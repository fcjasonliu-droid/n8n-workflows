# 调研深度达标判据 v1.0（Jason 拍板标准 2026-09-08）

> **要解决的问题**：Jason 质疑「web 搜关键词挖到 10 个就说有效果，但深挖可以到 100 个——怎么算深度够了？」
> **核心原则**：深度达标**不看数量**，看**三个可验证信号**：收敛曲线、覆盖率、证据链。

---

## 一、为什么"数量"不能当标准

- "挖了 N 个有效客户"是**自报绩效**，没有上限参照 → 永远无法自证够深
- 正确问法不是"挖了多少"，而是"**解空间还有多少没扫到？新增速度是否已收敛？**"

---

## 二、深度达标 = 三个可验证信号

### 信号 1：收敛曲线（递减收益判据）

每次搜索轮次记录**新增有效线索数**，画递减曲线：

| 轮次 | 新增有效线索 | 判定 |
|---|---|---|
| R1 | 34 | 继续（大量新增）|
| R2 | 18 | 继续 |
| R3 | 7 | 继续（仍有）|
| R4 | 2 | **接近收敛** |
| R5 | 1 | **✅ 收敛达标**（新增 < 上轮 30% 持续 2 轮）|

**判据**：连续 2 轮新增 < 上一轮 30%（或绝对值 < 3 条）→ 判定收敛，可停。
若每轮仍在大量新增 → **没到深度，继续搜**。

### 信号 2：覆盖率（解空间界定）

动手前先**列出完整搜索矩阵**，每轮标记已扫格子：

```
关键词维度 × 渠道维度 × 地理维度
 产品词(3)  × Google/LinkedIn/海关数据/阿里/B2B(5) × 目标国(3-5)
 = 45-75 个格子
```

**判据**：全部格子至少扫过 1 轮；已扫格子用 ✓ 标记（写进搜索日志）。
**未扫格子在报告里显式列出**（不能只报"找到 10 个"）。

### 信号 3：证据链（每条线索可信度分层）

| 级别 | 定义 | 判定 |
|---|---|---|
| **A 硬源** | 海关数据 + 官网/邮箱 + 社媒 三重交叉 | ✅ 可发开发信 |
| **B 二手** | 双源交叉（官网 + LinkedIn 或 海关 + 官网） | ✅ 可发开发信 |
| **C 候选** | 单源发现（仅目录/仅搜索快照） | ⚠️ 只算候选，不算有效 |

**判据**：报告中每条线索**标注证据级别**；只有 A/B 计入"有效客户"。
单源 C 级 → 继续反推补证，直到升 B 或放弃。

## 三、电商反推专项（独立站/电商 → 真实买家）

电商反推 = 从平台店铺/品牌反查背后的**进口商/批发商**。深度标准：

```
店铺/品牌名
  → 反查公司注册名（whois / 网站 footer / 备案）
  → 反查主营（是卖 ESD 的还是杂货铺？）
  → 反查进口记录（海关数据里有没有进过目标 HS 编码？）
  → 找到决策人 + 邮箱/WhatsApp/LinkedIn
```

**反推闭环判据**：一条线索必须走到**第 5 步（拿到可投递联系方式）**才算"一条有效线索"。
卡在 1-3 步 = 半成品，不计入有效。

---

## 四、执行要求（落到每次调研）

1. **每次调研先写搜索矩阵**（关键词×渠道×地理），Jason 过目后开跑
2. **每轮记录**：轮次 | 新增 | 累计 | 已扫格子 | 收敛判断 → 写进 `search_log.md`
3. **报告末尾必须有**：
   - 收敛曲线表（证明挖到收敛，不是中途停）
   - 覆盖率表（证明格子扫全，不是漏了大块）
   - 证据分层统计（A/B/C 各多少，附明细）
4. **诚实失败机制**：某格 0 结果也要记录（"X 渠道无结果"是有效信息，不是失败）

## 五、反例 vs 正例

**❌ 不及格报告**："我搜了 10 个关键词，找到 25 个潜在客户，其中 12 个有效"

**✅ 达标报告**：
```
搜索矩阵：ESD mat × [Google/LinkedIn/海关/阿里] × [US/DE/VN/BR] = 48 格
扫描进度：48/48 全扫 ✓（附每格结果摘要）

收敛曲线：
  R1: +34  R2: +18  R3: +7  R4: +2  R5: +1  → ✅ 连续2轮<30%，收敛

证据分层：
  A 级(硬源)：  9 条 → 附公司/邮箱/海关记录
  B 级(双源)： 18 条 → 附公司/邮箱
  C 级(候选)： 11 条 → 未计有效，待补证
  合计有效(A+B)：27 家可发开发信
```

## 六、本标准的适用范围

| 场景 | 适用 |
|---|---|
| web 搜关键词找客户/供应商 | ✅ |
| 电商网站反推真实买家 | ✅ |
| 海关数据挖掘 | ✅（矩阵=HS编码×国家×年份）|
| 市场调研/竞品分析 | ✅（矩阵=竞品×渠道×地区）|
| 单条客户深度背调 | 部分（用证据链分层，收敛曲线不适用）|
